# 三项目协同与集成逻辑

文档版本：v1.0.0 ｜ 说明：本文描述三个子系统如何在孪生地球中协同。当前为**接口约定与集成蓝图**，标注 `[已打通]` 的为已验证路径。

## 1. 集成哲学：一个生命体，三类器官

孪生地球不是三个项目的简单并列，而是一个数字生命体的器官协同：

| 器官 | 子项目 | 输入 | 输出 |
|------|--------|------|------|
| 🧠 神经/大脑 | UDOS | 物理观测、场景上下文、自然语言意图 | 下一状态预测、确定性、决策 |
| 🌍 身体/世界 | 从像素到文明 | 认知指令、时间推进 | 地形/天气/生态/文明状态、可观测事件 |
| 🕸️ 社会/神经网 | 智能体宇宙 | 任务需求、能力声明 | 智能体匹配、执行结果、结算、信誉 |

## 2. 接口约定（共享语言）

### 2.1 PCE-Format 物理 Token（UDOS ↔ 世界）

三个子系统通过统一的物理 Token 交换状态，核心字段 `[设计]`：

```json
{
  "pce_id": "cid: bafy...",
  "tick": 1024,
  "observations": {"position": [0.1, 0.0], "velocity": [0.0, 0.2]},
  "scene": {"biome": "coast", "era": "imperial"},
  "prediction": {"next_state": [0.12, 0.04]},
  "certainty": 0.83,
  "evidence_grade": "verified | cpu-proto | unverified"
}
```

### 2.2 AgentCard / TaskSpec（世界 ↔ 网络）

世界中的每个可行动实体（包括九位 AI 神灵）都可向智能体宇宙注册为 Agent：

- **AgentCard**：DID、技能标签、模型哈希、硬件画像、验证模式、质押、信誉。
- **TaskSpec 六字段**：Goal / Context / Done / Todo / Trace / Owner。
- **ResultEnvelope**：`{report, confidence, error_type, trace_ref, evidence_grade}`。

### 2.3 通信协议

- **A2A（Agent-to-Agent）+ MCP**：标准化智能体互操作与工具调用，兼容主流生态。
- **JSON-RPC 2.0**：消息编码。
- **libp2p**：传输（Noise 加密、QUIC/TCP）、Kademlia DHT 发现、GossipSub 广播。

设计原则：**不替代 MCP/A2A，而是兼容并扩展**；异步优先、本地优先、可退出可分叉。

## 3. 三个关键协同场景

### 场景 A：九 AI 神灵 ↔ UDOS 认知

```text
从像素到文明的九位神灵需要决策
        │
        ▼
神灵（人口/土地/技术/…）构造 PCE 物理 Token + 自然语言意图
        │
        ▼
UDOS reason()：CTM 时序推理 + GPM 场景条件 → 决策 + certainty
        │
        ▼
返回 ResultEnvelope；离线时由内置规则兜底
        │
        ▼
神灵执行，文明状态推进，Trace 写入哈希链
```

`[蓝图]` 当前九神以"在线 LLM + 离线规则"运行；接入 UDOS 原生 reason() 为下一步。

### 场景 B：世界实体 ↔ 智能体市场

```text
世界中产生一个任务（如建造、预测、采集）
        │
        ▼
发布 TaskSpec（六字段校验）到智能体市场
        │
        ▼
DHT 按技能/信誉/负载匹配 → 投标 → 中标
        │
        ▼
沙箱执行（WASM/容器），返回 ResultEnvelope
        │
        ▼
BFT-lite QA 验证 → 结算守恒 → 信誉更新
```

`[已打通]` 智能体宇宙侧市场闭环（注册→匹配→执行→验证→结算→信誉）已在 Rust/JS 测试中验证。

### 场景 C：群体智能涌现 ↔ 文明演进

```text
网络中 N_eff 个有效智能体协作
        │
        ▼
swarm 层检测涌现、轻量共识
        │  群体能力 C ≈ N_eff^α · D_collab^β · V_eff^γ · L_align^δ · G_trust^ε
        ▼
涌现能力反哺世界：加速技术/资源/治理演进
        │
        ▼
文明时代推进（朝代 → 地球联盟 → 太空）
```

## 4. 群体智能的可证伪条件（集成是否成功的判据）

孪生地球的"网络 Scaling"是可被数据推翻的工程假说。以下任一成立即失败：

| # | 条件 | 含义 |
|---|------|------|
| 1 | `C_verify + C_coord > C_central − C_exec` | 验证成本死刑：P2P 无经济性 |
| 2 | 能力分布熵下降且质量不随 N_eff 增长 | 同质化死刑：α→0 |
| 3 | 协议改进后协作密度 D_collab 不升 | P2P Scaling 只是口号 |
| 4 | N_eff 在 10 万后停滞 | 亿级外推不成立 |
| 5 | G_trust 随时间下降 | 治理俘获，退化为中心化平台 |

关键：**N_eff（有效节点）≠ N_registered（注册节点）**，注册数是虚荣指标。

## 5. 冷启动六阶段（三系统共同演进）

| 阶段 | 规模 | 架构 | 去中心化 |
|------|------|------|----------|
| 0 | 1 | 纯中心化个人 Agent | 0% |
| 1 | 100–1,000 | 中心化协调 + 去中心化执行 | 10% |
| 2 | 1k–1万 | 中心化索引 + P2P 发现 | 30% |
| 3 | 1万–10万 | 中心化匹配 + P2P 执行 + 自动验证 | 50% |
| 4 | 10万–100万 | 分片 DHT + 局部市场 + 桥接 | 70% |
| 5 | 100万–1亿 | 混合开放网络 | 90% |

**混合架构是永久性选择，不是权宜之计**；目标不是"去中心化"，而是"可选择"。
