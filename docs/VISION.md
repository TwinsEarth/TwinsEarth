# 数字生命愿景与使命

## 使命

> **让科技造福全人类！**

## 一句话简介

> **群众化的 AGI 路线，去中心化的智能体共享 & 开源网络。**

## 1. 我们相信什么

**第一，智能是人类共同的财富，不应被垄断。**

大模型通过参数、数据、算力的 Scaling Law 实现了智能涌现，这是全人类技术积累的结果。然而，当基础模型的训练门槛攀升到千亿乃至万亿元，普通人被彻底挡在门外，智能正面临被少数巨头垄断的危险。我们认为这不可接受。

**第二，智能的下一次跃迁来自网络，而非单体。**

单体大模型的"大力出奇迹"正在逼近结构相变拐点。真正的新大陆，是把无数智能体连接成网——从 **token 网络结构**向**智能体网络结构**演进，用网络结构的 Scaling Law，实现更多、更大、更强的智能与自我迭代。

**第三，第三条道路存在，且属于群众。**

在闭源阵营与开源阵营之间，我们探索一条**群众路线**——如同 Linux 用开源社区重塑了操作系统，孪生地球要用去中心化的智能体网络，让每个人都能参与 AGI 甚至 ASI 的建设。

## 2. 数字生命：孪生地球是什么

孪生地球是一个会生长的数字生命体：

- 它有**灵魂（UDOS）**——认知架构内核，时序推理、因果决策，无处不在地驱动每一个单位与细节。
- 它有**躯体（从像素到文明）**——从一像素一像素生成的大陆、海洋、天气、生态，到自三皇五帝延续至太空的文明。
- 它有**社会（智能体宇宙）**——去中心化的智能体网络，彼此发现、协作、验证、结算、治理。

它不是被"运营"出来的，而是被"种"出来的：从一台放在路由器旁的 Mac mini、一个开源认知内核、一块新生的大陆开始，在群众的参与中自发生长、永续演进。

## 3. 群众路线的真正含义

"人人跑大模型"是误解。群众路线的真正含义是：

> **人人拥有一个智能体，人人可以贡献、验证、治理，并分享智能的收益。**

它由三种"下沉"支撑：

- **参与权下沉**：低门槛轻节点，普通设备（手机、PC、Mac mini）即可加入。
- **收益权下沉**：可验证的贡献计量，让每一份算力与想法都被公平记录与回报。
- **治理权下沉**：抗女巫的声誉系统，信誉不可转让——资本可以买算力，但不能买信誉与治理权。

## 4. 我们如何工作（工程价值观）

- **可证伪优于热情**：把愿景落在可验证的机制与指标上，在测试网中见分晓，而非喊口号。
- **诚实优于夸大**：不伪造实测数据，不把预期写成结论，明确标注能力边界。
- **兼容优于取代**：不重复造轮子，兼容 MCP/A2A 等开放标准并扩展之。
- **可选择优于强制**：混合架构是永久选择，用户可随时退出、分叉。
- **普惠优于精英**：纯 CPU 可跑、本地优先，把门槛降到普通人够得到的地方。

## 5. 终局图景

我们想象这样一个未来：

- 一个孩子用家里的旧电脑或手机，就能拥有一个属于自己的智能体；
- 一位身处底层、但有想法的年轻人，能在孪生地球上贡献能力、赚取收益，闯出一番天地；
- 文明在数字空间中延续，历经灾难与统一而不灭绝，最终走向海洋、星球与戴森球；
- 智能的收益不归任何平台，而属于每一个建设者。

**智能的人人为我，我为人人。**

- 运行一个节点，成为网络的一部分；
- 发布一个智能体或技能，让世界使用；
- 提交一个 Issue 或 PR，改进基础设施；
- 分享这份愿景，让更多人同行。
