# 孪生地球整体系统架构

文档版本：v1.0.0 ｜ 证据口径：本文为架构设计文档，标注 `[设计]` 的为目标形态，标注 `[已实现]` 的为子项目当前可运行能力。

## 1. 架构总览

孪生地球是一个**分层、可证伪、本地优先**的数字生命系统。它在三个时间尺度上运行：

- **毫秒—秒级（认知）**：UDOS 对物理世界做时序推理与因果决策。
- **秒—小时级（生成）**：从像素到文明持续生成地形、天气、生态与文明事件。
- **小时—年级（协作）**：智能体宇宙通过 P2P 网络协调海量智能体，完成市场交易与治理。

三层共享统一的数据语言 **PCE-Format（物理 Token）**，并以内容寻址（CID）与哈希链保证可追溯。

## 3. 三大子系统的内部架构

### 3.1 🧠 UDOS 推演引擎（认知内核 · Python）

```
udos-reasoning-engine/
├── udos/
│   ├── core/        # CTM 连续思维机：内部时间轴、神经元级时序、同步即表示
│   ├── gpm/         # GPM 场景内化：HyperLoRA + Perceiver，可无损注入/移除
│   ├── pava/        # 保序校准、split-conformal 区间、OOD/漂移检测
│   ├── causal/      # 混合修正、反事实、辨识归因、风险分级
│   ├── world/       # 物理闭环、形态重定向、可供性、数字孪生
│   ├── multiagent/  # 自规划课程、自训练、四拓扑多智能体
│   ├── security/    # PBKDF2、RBAC、加密备份、kill-switch
│   ├── intel/       # EWMA、奇点门、能力向量、S曲线 ETA、Brier 记分
│   ├── kvcache/     # HBM→DDR→SSD→remote 多级缓存
│   ├── brain/       # 树突区室、树突门控、DHS 调度
│   └── finesim/     # 被动电缆、Hodgkin–Huxley、NMDA 时序抑制
├── checkpoints/     # 主模型 PhysicsPredictor，52191 参数，向后兼容
└── server/          # HTTP 服务、Prometheus 指标
```

设计纪律：受前沿工作启发的模块只在 CPU 上做**可验证的机制对齐（analogy, not reproduction）**；缺少 GPU/在线 LLM 等条件时显式返回 `ENV_BLOCKED/503`。

## 4. 数据流：一个完整的"数字生命时刻"

```text
① 物理观测窗口（位置/速度/环境）
        │
        ▼
② UDOS CTM 推理 + GPM 场景条件 → 下一状态预测 + certainty   [认知]
        │ （PCE-Format 物理 Token, CID 内容寻址）
        ▼
③ 从像素到文明把预测落地为地形/天气/生态/文明事件           [生成]
        │
        ▼
④ 九 AI 神灵 / 网络智能体经 DHT 发现、市场匹配、调用执行      [协作]
        │
        ▼
⑤ 验证层（抽样/冗余/TEE/zkML/仲裁）给出可信结论
        │
        ▼
⑥ 链上/账本结算，更新不可转让信誉与质押                      [经济]
        │
        ▼
⑦ 结果反哺 UDOS（自训练/自进化）与文明状态，进入下一时刻       [闭环]
```

## 5. 关键不变量

- **结算守恒**：`balance_sum = total_deposits − total_slashed`；质押转入锁定账户、不凭空消失。
- **责任不丢失**：TransferBundle 六字段（Goal/Context/Done/Todo/Trace/Owner）校验通过才转移责任。
- **不错误停止**：BFT-lite `n≥3f+1`，equivocation 整轮作废，沉默超阈值触发 view change。
- **文明不灭绝**：允许倒退，但"存亡续绝"底线保证延续。
- **信誉不可转让**：资本可买算力，但不能买信誉与治理权。

## 6. 可信边界（如实声明）

- C#/Unity 工程需 Tuanjie 编辑器构建，云电脑（Linux）不编译该子项目，仅做结构与文本核查。
- 跨主机多节点 DHT 实际互联、链上主网结算为下一阶段目标。
- UDOS 的 GPM/CTM 双引擎部分为 CPU 机制对齐，非上游规模复现；详见各子项目"边界声明"。
